## 双色球选号系统优化（2026-05-04 09:01）

**复盘结论：**
- 20期100注统计：总奖金45元，投入200元，ROI -77.5%
- 红球命中率严重不足（最高仅3红），中奖完全依赖蓝球
- 蓝球命中率9%，高于理论6.25%，表现良好

**问题原因：**
1. 和值范围过窄（90-120），实际80-120更常见（占66%）
2. 连号过度压制（惩罚权重0.9），实际56%开奖有连号
3. 冷热权重失衡：冷门号权重偏高，热门号权重不足

**优化措施（已执行）：**

修改 `/vol1/1000/code/lottery-ssq/config.json`：

1. **和值范围：** `[90, 120]` → `[80, 120]`
2. **连号惩罚（balanced策略）：** `0.9` → `0.95`
3. **热门号权重：** `1.0` → `1.15`
4. **温号权重：** `1.15` → `1.1`
5. **冷门号权重：** `1.05` → `0.95`

**预期效果：**
- 扩大和值范围，覆盖更多开奖组合
- 减少连号压制，提高连号组合入选率
- 提高热门号权重，增加红球命中概率
