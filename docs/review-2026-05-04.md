## 🔍 问题诊断

### 1. 红球选号质量不足
- **现象：** 最高命中仅3红，无4红及以上
- **原因：**
  - 和值范围90-120略窄，错过80-89区间（占19%）
  - 连号惩罚权重（0.9）过高，抑制了56%的连号组合
  - 冷门号权重（1.05）偏高，热门号权重不足

### 2. 中奖完全依赖蓝球
- **现象：** 9次中奖全部为蓝球命中
- **原因：** 红球选号质量不足，无法与蓝球形成组合中奖

### 3. 投入产出严重失衡
- **现象：** ROI -77.5%，每注平均收益0.45元（成本2元）
- **原因：** 红球贡献为0，仅靠蓝球无法提升收益

## 💡 优化建议

### 1. 调整和值范围
```json
// 当前配置
"sum_range": [90, 120]

// 建议调整
"sum_range": [80, 120]
```
**理由：** 80-120区间覆盖66%的开奖，90-120只有47%。

### 2. 调整连号策略
```json
// 当前配置
"consecutive_penalty": 0.9

// 建议调整
"consecutive_penalty": 0.95  // 或 1.0（不惩罚）
```
**理由：** 56%的开奖有连号，不应过度压制。

### 3. 调整冷热权重
```json
// 当前配置（balanced策略）
"hot": 1.0,
"warm": 1.15,
"cold": 1.05

// 建议调整
"hot": 1.15,   // 提高热门号权重
"warm": 1.1,
"cold": 0.95   // 降低冷门号权重
```
**理由：** 实际开奖中，热门号出现频率远高于冷门号。

### 4. 考虑增加候选池
```json
// 当前配置
"candidate_pool_size": 3000

// 可考虑增加
"candidate_pool_size": 5000
```
**理由：** 更大的候选池可能产生更优组合。

### 5. 维持蓝球策略
- 当前蓝球命中率9%，高于理论6.25%，表现良好
- 无需调整
